# Изразцы Стамбула

Три в ряд по Стамбулу в одном файле `index.html`, без сборки и зависимостей.

- 8 фишек: Айя-София, Голубая мечеть, Галатская башня, Девичья башня, Босфорский мост, трамвай, симит, кошка (на каждом уровне 6 из них).
- Особые фишки: чайка (4 в ряд), вапур (уголок), назар (5 в ряд) и их комбинации.
- Препятствия: пыльные клетки, спящие кошки, ящики с чаем, тележки симитчи.
- 12 районов на карте маршрута, дальше бесконечные уровни; задание дня; бонусы за лиры; финальный салют.
- Звук на WebAudio, лёгкая вибрация, прогресс хранится в браузере.

Цели уровней подобраны симуляцией: движок (`// ==ENGINE==`) и уровни (`// ==LEVELS==`) — чистый JS без DOM, их можно прогнать в Node.

## Установка на сервер с nginx

На сервере под root:

```
curl -fsSL https://raw.githubusercontent.com/koid38/super-meme/HEAD/istanbul/deploy.sh | sh
```

Скрипт кладёт игру в папку сайта как `/istanbul/`, проверяет, что nginx её отдаёт, и перенаправляет туда голый адрес, если у сайта нет своей стартовой страницы. Повторный запуск обновляет игру.

Версия 1.0 — коммит `8dd2516` в ветке `claude/vaiucodeing-capabilities-mjz15p`.
